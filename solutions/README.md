# ⚠️ Solutions: spoilers ahead

This folder holds a commented template solution for every assignment. The folders mirror the level
folders, so the solution for

`beginner/03-numbers-and-strings/assignments/03-temperature-converter/exercise.py`

is at

`solutions/beginner/03-numbers-and-strings/assignments/03-temperature-converter/exercise.py`.

**Try the assignment first.** Open a solution once your tests are green (to compare approaches)
or once you have been stuck for a while (to get unstuck). The comments explain *why* the code is
written the way it is, which is often more useful than the code itself.

A solution is not the only correct answer. If your version passes the tests, it is correct.
The template is one clear way to do it.

CI runs every test against these solutions on every push:

```bash
PLP_SOLUTIONS=1 pytest
```
